# DRIVE OIL

Интернет-витрина моторных масел и фильтров с корзиной, отзывами, избранным, заказами и отдельным кабинетом владельца.

## Что входит

- Гостевая витрина: `index.html` — каталог, избранное, корзина и оформление заказа.
- Кабинет владельца: `admin.html` — вход, заказы, отзывы, редактирование товаров и URL фотографий.
- Сервер и SQLite-база: `server.js`.

## Запуск локально

Требуется Node.js 22.5 или новее (используется встроенный SQLite).

```powershell
$env:PORT='8002'
$env:ADMIN_PASSWORD='придумайте-надёжный-пароль'
node server.js
```

После запуска:

- Витрина: `http://localhost:8002`
- Кабинет владельца: `http://localhost:8002/admin.html`

## Фотографии товаров

В кабинете владельца откройте карточку нужного товара и вставьте прямую ссылку в поле **URL изображения**. После сохранения фотография отобразится на витрине. Если ссылка не указана, показывается уникальная запасная карточка с названием товара.

## Публикация на GitHub

1. Создайте новый пустой репозиторий на GitHub.
2. В папке проекта выполните:

```powershell
git init
git add .
git commit -m "Initial DRIVE OIL store"
git branch -M main
git remote add origin https://github.com/ВАШ-ЛОГИН/ВАШ-РЕПОЗИТОРИЙ.git
git push -u origin main
```

Файл базы `driveoil.sqlite` намеренно не попадёт в GitHub: в нём могут быть персональные данные заказчиков. На новом сервере база создастся автоматически при первом запуске.

## Важно

GitHub Pages подходит только для статичных сайтов и не поддерживает этот сервер с SQLite. Для работающего оформления заказов разместите проект на хостинге с поддержкой Node.js.
